# ChatGPT Plugin Translations

Keep the product name `Agent Enhancer Utilities` unchanged in every locale.

## French

**Display name**

Agent Enhancer Utilities

**Short description**

Outils fiables pour agents IA

**Long description**

Utilisez Agent Enhancer Utilities comme couche de fiabilité pour les workflows répétés, planifiés ou parallèles exécutés avec d’autres plugins. Ses 37 outils déterministes planifient et jalonnent les workflows protégés, coordonnent des identifiants opaques, inspectent les contrats MCP et x402 et testent des scénarios limités de défaillance d’API. Le service est gratuit, sans compte, n’intercepte pas automatiquement les autres plugins et n’offre aucun transfert, portefeuille, règlement ou paiement réel.

**Starter prompts**

1. Sécurise un import parallèle réalisé avec un autre plugin : évite les doublons et limite le nombre d’agents actifs à deux.
2. Crée une séquence temporaire de 429 à 200 pour vérifier que mon client HTTP respecte Retry-After.
3. Compare deux exigences x402 et signale tout changement de montant, destinataire, réseau, actif ou ressource.

## German

**Display name**

Agent Enhancer Utilities

**Short description**

Tools für zuverlässige Agenten

**Long description**

Nutze Agent Enhancer Utilities als Zuverlässigkeits-Sidecar für wiederholte, geplante oder parallele Abläufe mit anderen Plugins. Die 37 deterministischen Tools planen und protokollieren geschützte Abläufe, koordinieren undurchsichtige Kennungen, prüfen MCP- und x402-Verträge und testen begrenzte API-Fehlerpfade. Der Dienst ist kostenlos, benötigt kein Konto, fängt andere Plugins nicht automatisch ab und ermöglicht keine Überweisungen, Wallets, Abrechnungen oder echten Zahlungen.

**Starter prompts**

1. Sichere einen parallelen Import mit einem anderen Plugin ab: vermeide Duplikate und begrenze aktive Agenten auf zwei.
2. Erstelle eine temporäre 429-zu-200-Fehlerfolge, um zu testen, ob mein HTTP-Client Retry-After beachtet.
3. Vergleiche zwei x402-Anforderungen und markiere Änderungen bei Betrag, Empfänger, Netzwerk, Asset oder Ressource.
